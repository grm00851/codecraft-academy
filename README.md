# CODECRAFT Academy

Практическая академия программирования на React и TypeScript: **218 уроков в семи самостоятельных программах**. Основной маршрут веб-разработчика состоит из HTML, CSS, JavaScript, TypeScript и React: это 166 уроков и около 513 часов с практическими заданиями, проектами, повторением и проверками. Python и C++ — отдельные дополнительные направления.

Веб-маршрут рекомендуется проходить по порядку: **HTML → CSS → JavaScript → TypeScript → React**. Он охватывает семантическую разметку, адаптивный интерфейс, логику приложения, работу с API, строгие типы, архитектуру компонентов и публикацию проекта. Итоговый проект React — платформа обучения с каталогом и уроками, прогрессом, профилем, экзаменами, сертификатами, тестами и HTTPS-демо.

В каждом из 218 уроков есть цель, расширенное объяснение темы, пример кода, разбор его частей, конкретный пример ошибки с исправлением, практическое задание, критерий самопроверки и вопрос на понимание. Введение к каждому курсу объясняет, что это за язык или технология, где её применяют и что предстоит собрать. В расширенных модулях отдельно разбираются доступность, безопасность, сетевые ошибки, тестирование, отладка, архитектура и производительность.

Материалы и расширенные разборы загружаются отдельными файлами при открытии выбранного курса. Главная страница и каталог используют компактные карточки курса, поэтому браузер не загружает все тексты уроков одним стартовым пакетом.

## Профиль, проекты и настройки

- Профиль показывает уровень из 20 ступеней, опыт в XP и 33 достижения за уроки, экзамены, проекты и завершение учебных маршрутов.
- Фотографию можно приблизить и двигать по горизонтали и вертикали. Круглый предпросмотр использует тот же квадратный фрагмент, который будет сохранён.
- Страница проектов — личный чек-лист: код пишется в редакторе пользователя, а сайт хранит отмеченные этапы и ссылки на репозиторий/демо. Он не проверяет исходники автоматически.
- В настройках есть отдельные разделы для темы, оценки приложения, контактов и напоминаний. Отзыв можно скачать как файл; он не отправляется автоматически. Контакты и прогресс хранятся только в локальном браузере без шифрования.
- Напоминание работает, пока сайт открыт и браузер разрешил уведомления. Для уведомлений при закрытой вкладке нужен отдельный push-сервис.

## ИИ-наставник

На странице ИИ можно подключить совместимый с Chat Completions API сервис: укажи его HTTPS-адрес, название модели и собственный ключ. Ключ существует только в памяти открытой вкладки, не попадает в сохранённый профиль или резервную копию и удаляется при уходе со страницы. Запросы отправляются напрямую выбранному провайдеру; его API должен разрешать CORS. Такой режим предназначен для личного локального использования. Для публичной публикации нужен серверный proxy, который хранит секрет на сервере и не раскрывает его посетителям.

## Запуск в Windows

Открой PowerShell в папке проекта и выполни:

    npm.cmd install
    npm.cmd run dev

Оставь терминал открытым и перейди по адресу Local, который Vite напечатает в терминале. Если порт 5173 занят, Vite выберет следующий свободный порт.

Для production-сборки:

    npm.cmd run build
    npm.cmd run preview

## Публикация на GitHub Pages

В проект добавлен GitHub Actions workflow: он устанавливает зависимости, собирает сайт и публикует `dist` при каждом обновлении ветки `main` или `master`. Путь для обычного репозитория `/<имя-репозитория>/` определяется автоматически; для репозитория вида `username.github.io` используется корень домена. Для загрузки проекта Visual Studio Code не нужен — можно воспользоваться GitHub Desktop.

1. Распакуй архив и установи GitHub Desktop, затем войди в свой аккаунт GitHub.
2. В GitHub Desktop выбери **File → New repository** и назови репозиторий `codecraft-academy`.
3. Скопируй содержимое распакованной папки в созданную GitHub Desktop папку репозитория, включая `.github` и `public`; подтверди замену README, если Windows спросит.
4. В GitHub Desktop создай commit, затем нажми **Publish repository**. Если сайт должен быть общедоступным, опубликуй код открыто: незакрытый исходный код станет виден всем.
5. В репозитории открой **Settings → Pages** и выбери источник **GitHub Actions**.
6. Открой вкладку **Actions** и дождись завершения задачи **Publish CODECRAFT Academy to GitHub Pages**.
7. Адрес опубликованного сайта GitHub покажет в **Settings → Pages**. Для обычного репозитория он выглядит как `https://username.github.io/repository/`.

После загрузки изменений сайт пересобирается и публикуется автоматически. GitHub Pages отдаёт его по HTTPS; проект настроен на адрес GitHub Pages, а не на открытие через VS Code.

## Установка как приложения

Сначала открой опубликованный HTTPS-адрес сайта, затем выбери подходящий способ:

- **Android, Chrome:** меню ⋮ → **Установить приложение** или **Добавить на главный экран**.
- **iPhone/iPad, Safari:** **Поделиться** → **На экран «Домой»**.
- **Windows, Chrome или Edge:** значок установки в адресной строке или меню браузера → **Установить CODECRAFT Academy**. Приложение появится среди приложений Windows; его можно закрепить на панели задач.
- **macOS, Safari:** меню **Файл → Добавить в Dock**. В Chrome открой меню установки сайта как приложения.

Манифест и иконки добавлены. Service worker кэширует оболочку сайта и уже загруженные материалы курсов, поэтому ранее открытые страницы доступны и без сети; первый визит и ещё не открытые курсы требуют подключения к интернету.

## Экзамены, дипломы и прогресс

- Экзамен выбирает до 25 вопросов из тем курса и ограничен по времени. В коротких курсах проверяются все доступные темы.
- Итог: 0–100 баллов; порог зачёта — 80. Результат перечисляет ошибочные вопросы и уроки для повторения.
- Диплом курса доступен после завершения всех уроков и успешного экзамена. На нём отображаются никнейм, навыки программы, балл и дата; документ можно распечатать или сохранить в PDF.
- Никнейм, фото профиля, выполненные уроки, проекты, тема и результаты хранятся локально в браузере. В настройках доступна JSON-резервная копия.

Практические задания выполняются в редакторе кода; критерий в приложении помогает провести самопроверку. Экзамен проверяет знания по вопросам, а итоговый проект — по чек-листу. Диплом является документом платформы, а не аккредитованным подтверждением квалификации.

## Технологии

React, TypeScript и Vite. Тяжёлые редакторы и Python-рантайм удалены из обязательных зависимостей; основные материалы работают без внешних API. Фото аватара обрабатывается в браузере и масштабируется до компактного квадратного изображения.
